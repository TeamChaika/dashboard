# Локальное тестирование бота

## Проблема с локальной установкой

Для Python 3.14 нет предкомпилированных пакетов для `aiohttp==3.9.1`, который требуется для `aiogram==3.3.0`. 
Установка требует компиляции из исходников, для чего нужен Rust.

## Решения

### Вариант 1: Docker (рекомендуется) ✅

На сервере с Docker выполните:

```bash
# Пересобрать образ с новыми зависимостями
docker compose build --no-cache bot

# Запустить бота
docker compose up bot

# Или в фоновом режиме
docker compose up -d bot

# Проверить логи
docker compose logs -f bot
```

### Вариант 2: Установить Rust

Если нужно запустить локально:

1. Установите Rust: https://rustup.rs/
2. Затем установите зависимости:
   ```bash
   py -m pip install -r requirements.txt
   ```

### Вариант 3: Использовать Python 3.11 или 3.12

Для этих версий Python есть предкомпилированные пакеты:

```bash
# Установите Python 3.11 или 3.12
# Затем установите зависимости
pip install -r requirements.txt
```

## Проверка зависимостей

После установки зависимостей запустите тестовый скрипт:

```bash
py test_bot.py
```

Скрипт проверит:
- ✅ Установлены ли все зависимости
- ✅ Наличие `__version_info__` в `marshmallow` (исправление ошибки)
- ✅ Загрузку `env.py` и наличие `BOT_TOKEN`
- ✅ Импорт модулей бота

## Запуск бота

После успешной проверки:

```bash
py bot.py
```

Или через Docker:

```bash
docker compose up bot
```
